retry/with-retry

package.sema:73
(retry/with-retry thunk . opts)

Run thunk, retrying failures with exponential backoff; return its value. Options: :max-attempts (3), :initial-delay ms (200), :max-delay ms (10000), :multiplier (2.0), :jitter fraction (0.2), :retry-if (fn (err) bool), :on-retry (fn (attempt err delay)), :sleep-fn (for testing). After :max-attempts failures re-raises as "retry: giving up after N attempts — <msg>".

retry/backoff-delays

package.sema:81
(retry/backoff-delays opts)

Return the list of pre-jitter delays (ms) the retry policy would sleep between attempts. Pure: length is (- :max-attempts 1); jitter is ignored (it is randomized at runtime).

retry/circuit-breaker

package.sema:94
(retry/circuit-breaker . opts)

Create a circuit breaker (closed → open → half-open state machine). Options: :failure-threshold (5) consecutive failures to trip, :reset-timeout ms (30000) before an open breaker admits a probe, :half-open-max (1) concurrent probes, :clock-fn (for testing; defaults to time-ms). Use with retry/with-breaker.

retry/with-breaker

package.sema:144
(retry/with-breaker breaker thunk)

Run thunk through the breaker; return its value. Closed: failures count toward the threshold. Open: raises "retry: circuit open" immediately until :reset-timeout elapses. Half-open: admits :half-open-max probes; a probe success closes the breaker, a probe failure re-opens it.

retry/breaker-state

package.sema:158
(retry/breaker-state breaker)

Return the breaker's current state: :closed, :open, or :half-open.

retry/rate-limiter

package.sema:166
(retry/rate-limiter opts)

Create a token-bucket rate limiter allowing :rate calls per :per milliseconds. Options: :rate (10), :per ms (1000), :clock-fn and :sleep-fn (for testing). The bucket starts full (burst up to :rate) and refills continuously. Use with retry/with-limit or retry/try-acquire!.

retry/with-limit

package.sema:204
(retry/with-limit limiter thunk)

Sleep until the limiter grants a token, then run thunk and return its value.

retry/try-acquire!

package.sema:209
(retry/try-acquire! limiter)

Take a token if one is available, without sleeping. Returns #t or #f.

retry/with-timeout

package.sema:217
(retry/with-timeout ms thunk)

Run thunk as an async task; raise an error if it isn't done within ms. On expiry the task is cancelled and in-flight offloaded I/O (http, shell, llm) is aborted. Sema's scheduler is cooperative: the thunk must yield (offloaded I/O, await, channel ops, async/sleep) to be preemptable — pure CPU loops or a blocking (sleep ...) cannot be interrupted.

README · Quick start README.md:18–31 
```sema
(import "sema-retry")

;; Retry a flaky HTTP call: 5 attempts, exponential backoff with jitter.
(retry/with-retry
  (fn () (http/get "https://api.example.com/data"))
  {:max-attempts 5 :initial-delay 200 :multiplier 2.0})

;; See exactly what the policy would sleep between attempts:
(retry/backoff-delays {:max-attempts 5 :initial-delay 200 :multiplier 2.0})
; => (200 400 800 1600)
```
